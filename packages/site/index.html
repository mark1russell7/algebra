What algebra is

An expression is one document, for example { "type": "add", "value": [x, y] }. Many evaluators read the same document. A new evaluator is a new answer to the same question. No document changes.

  • Float A fast value, and a bound of its rounding error.
  • Exact rational A value over bigint, always in lowest terms. Its error is 0.
  • Interval An interval that contains the true value.

Each evaluator states its error. A result without an error bound is not a result.
